# TryHackMe: Cyber Security 101 — Module 1: Introduction to Cyber Security

## What I Learned

### Offensive Security
Legally hacking systems to find how an attacker could get unauthorized access. It means finding and exploiting vulnerabilities before someone with bad intentions does.

### Defensive Security
Detecting threats, responding to them, and securing systems. This is monitoring alerts, investigating suspicious activity, and following incident response steps to contain and fix attacks. This is the core job of a SOC analyst.

### Security Research & Tools
Tools covered for security research and threat intelligence:

- **Shodan** scans the internet for exposed devices and systems, and shows what's vulnerable and what's properly secured.
- **VirusTotal** checks files and URLs against 70+ antivirus engines at once.
- **CVE Database** is a searchable list of publicly disclosed vulnerabilities, useful for checking known flaws in a specific software version.
- **Technical documentation (MAN pages)** is usually the first place to look when troubleshooting. You need to know how a system is supposed to work before you can figure out why it isn't.

## Key Takeaway

Offensive and defensive security depend on each other. You can't defend well without understanding how attackers think, and you can't attack (ethically) without knowing what defenders look for. Shodan and VirusTotal aren't just pentester tools either, SOC analysts use them daily when investigating IOCs.
